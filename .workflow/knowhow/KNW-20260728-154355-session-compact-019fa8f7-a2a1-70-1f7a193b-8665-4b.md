## Decisions
- **Trust is the sole Hook execution approval**: Untrusted configuration does not run; once its exact hash is trusted, its enabled command Hooks run without per-command or per-trigger approval.
- **Toggles are independent of `.pi/hooks.json`**: Rewriting Hook configuration for UI toggles would change its hash and force unnecessary re-review.
- **Stable handler fingerprints identify toggles**: Per-command state must survive reloads without relying only on array position.
- **Hook permission output is ignored for target tools**: `allow`, `ask`, `deny`, `block`, and PermissionRequest permission updates do not override the ordinary permission controller.
- **Native `pi-tui` replaces Maestro2 React/Ink UI**: Reuse interaction concepts while matching this repository’s existing `Component`/`Focusable` overlay patterns.
- **Explicit filter mode**: `/` enters filtering; ordinary letters remain available for actions outside filter mode.
- **Fallback remains available**: If custom TUI cannot open, `/hooks` uses the bounded confirmation workflow rather than becoming unusable.
