# npm pack --dry-run --json 的 prepack 输出混入 stdout — 用 /\[\s*\{/ 定位 JSON 数组

## 症状

`npm pack --dry-run --json`（或 `npm publish --dry-run --json`）时，prepack 脚本的输出混入 stdout：

- teammate/cockpit：`bundle-settings-core: materialized D:\...\node_modules\pi-maestro-settings-core`
- flow：`[pi-maestro-flow] Prepared canonical Pi directory from D:\pi-maestro-flow\.pi`

整段 `JSON.parse(stdout)` 失败；`lastIndexOf('[')` 会被 flow 的 `[pi-maestro-flow]` 前缀误导，截取到错误位置。

## 防护

1. 输出重定向到文件后，用正则定位 JSON 数组起点再解析：
   ```js
   const m = d.match(/\[\s*\{/);
   const j = JSON.parse(d.slice(m.index));   // j[0] = tarball 信息
   ```
   prepack 消息不以 `[{` 开头，正则不会误命中。
2. 字段名差异：npm pack 输出 `size`（packed 大小）与 `unpackedSize`；个别包可能输出 `packedSize`。取值用 `it.size ?? it.packedSize`。
3. 多包 dry-run 必须串行执行：Flow 的 prepack/postpack 共用 `packages/pi-maestro-flow/.pi/skills`，并发 pack 会出现 `ENOENT`/`ENOTEMPTY` 竞争。
4. MSYS/Git Bash 下 node 把 `/tmp/xxx` 解析为 `D:\tmp\xxx`：临时文件用仓库内相对路径（如 `.dryrun-<pkg>.log`），用后删除，避免污染工作区。
