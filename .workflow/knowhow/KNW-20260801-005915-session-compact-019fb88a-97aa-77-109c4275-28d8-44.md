## Decisions
- **Do not compact merely because a threshold intent survived until normal `agent_settled`**: Normal completion does not prove more work is needed, and post-task compaction can destroy useful detail.
- **Keep immediate emergency paths**: Context exhaustion, output-limit truncation, and genuine queued continuation require compaction before continuing.
- **Do not invoke full compaction directly inside the context transform**: That would violate the Pi/Maestro arbitration rule and can race Pi native compaction.
- **Re-evaluate on a later request instead of preserving an obsolete normal-completion intent indefinitely**: The next context pass can derive pressure from the current branch before provider dispatch.
- **Output tokens still share total capacity, but `maxTokens` is an upper bound**: Pi dynamically clamps the request, so the full model output ceiling is not reserved at every threshold calculation.
- **Preserve fail-closed summary capacity**: The 4,096 safety margin and minimum summary output checks remain mandatory.
