# Windows 下 pi install 读 USERPROFILE 而非 HOME；pi remove npm: 会卸载整个 npm 依赖树

## 症状

1. Git Bash 里 `HOME=/d/smoke-home pi install npm:pi-maestro-flow@x.y.z` 实际写入 `C:\Users\<user>\.pi`（真实 HOME）：pi（Node 程序）在 Windows 取 `USERPROFILE`，不认 `HOME`。fresh 环境 smoke 因此「静默装进真实环境」，settings.json 出现意外条目。
2. `pi remove npm:<pkg>` 会触发 npm uninstall，卸载 `~/.pi/agent/npm/node_modules` 下**整个依赖树**（v0.17.0 时一次移除 484 个包）。settings.json 中仍以绝对路径引用的其他包（如 `C:\Users\<user>\.pi\agent\npm\node_modules\pi-cockpit`）变成 MISSING，下次启动报路径缺失。

## 防护（并入发布 preflight）

1. fresh 环境 smoke 必须同时设置两个变量并验证安装落点：
   ```bash
   export USERPROFILE='D:\smoke-home'; export HOME=/d/smoke-home
   pi install npm:<pkg>@<version>
   ls /d/smoke-home/.pi/agent/npm/node_modules/<pkg>/package.json   # 确认落在 fresh 目录
   ```
2. remove 任何 npm: 源之前，先检查 `~/.pi/agent/settings.json` 的 packages 数组：若有绝对路径条目指向同一 `agent/npm/node_modules` 目录，先收敛注册形式（去重），再 remove。
3. 误删后的恢复：`pi install npm:<pkg>@<version>` 重装到同一路径，并把 settings 条目收敛为单一形式（绝对路径或 npm: 源二选一），避免同一包双源重复注册。
4. 重复注册症状：pi 启动报 `Tool "X" conflicts with ...`，同一 extension 的 src 路径出现两次。
