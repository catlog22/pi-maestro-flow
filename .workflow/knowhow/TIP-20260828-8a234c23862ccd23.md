When bounding a persisted cache or database, treat the complete artifact family as the input boundary: main file, metadata sidecars, SQLite WAL/SHM, and migration formats. Cap and validate all members before opening, parsing, or allocating; validate count/dimension/length relationships; publish through operation-unique temporary files plus an ownership/generation fence. A cap on only the main file can be bypassed by sidecar-backed data.
