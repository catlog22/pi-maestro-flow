A child-emitted teammate_proxy_cancel is not fixed merely because emission and cancelProxyDispatch each have tests. The IPC classifier and every nested onChildRequest bridge must route the control message to the cancellation handler; verify with one connected timeout-to-subtree teardown test. Current audit reproduced cancel downgraded to lifecycle event and deeper forwarding as unsupported tool.
