A prune manifest entry owns provider-visible serialized bytes for a compaction epoch. After first publication, spill persistence retries must not mutate replacement text: scope spill upgrade to callIds created in the current pass and freeze plain replacements after failure. Restored spill/minimal paths must be validated for expected-root containment, regular-file liveness, and content identity; persist one stable downgrade when invalid. Normal session shutdown must fence in-flight work without appending an empty authoritative manifest tombstone; destructive clearing belongs to successful compaction, explicit deletion, incompatible version, or bounded expiry. Structural tests must compare canonical serialized message equality and earliest divergence across failure-retry and shutdown-resume production order.
