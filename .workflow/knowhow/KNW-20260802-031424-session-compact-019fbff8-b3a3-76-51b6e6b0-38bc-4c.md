## Design

**Locked decisions:** implicit team via root dispatch correlationId; no TeamCreate/Delete; disk authority; reuse Flow Todo; preserve teammate/teammate-send/observe API; result-ready remains early publication; `agent_settled` alone enqueues result (intentional deviation from Claude Code explicit SendMessage); abort/permission/question remain direct; no silent direct fallback on disk error; no oldest eviction.

**State machine:** `STAGING → READY → CLAIMED → ACCEPTED → APPLIED → GC`; terminal `REJECTED | EXPIRED | DEAD`. Transitions via immutable file write + atomic rename + parent fsync. Stale CLAIMED reclaimed after 20s without heartbeat.

**Authority revalidation:** enqueue and apply both check route, canProxySendTo, session generation, lease epoch+nonce. Fenced agents may queue but not dispatch. Stale unauthorized → DEAD.

**Delivery:** same-process event + 50ms cross-process polling. One claimer per recipient. FIFO per sender+priority lane.

**Quota:** normal admission ceiling 512, last 64 slots reserved for critical (lifecycle/result/control); normal max 448; hard total 512 / ~48MiB. Full normal → `quota_exceeded`; critical still admitted until total 512.

**Capability negotiation:** workspace capability v2 advertised; legacy direct path only when negotiation explicitly chooses v1. Same logical message uses same messageId; never dual-injects.
